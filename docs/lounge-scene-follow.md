# 1:1 대화방의 자동 배경 전환 (2026-11-09)

1:1 대화방(내 방, 이야기 카드가 아닌 방)의 배경이 대화의 장소를 따라 바뀐다. 기준은 v4 엔진이 대화마다 기록하는 장면(`companion_state.scene`: 장소, 장소 종류, 하는 일, 때)이다.

## 규칙 (`src/lib/loungeSceneFollow.ts`)
- **시작**: 방을 열 때 장소가 분명하면 그 장소의 배경으로 바꾼다. 엔진 장면이 아직 없으면 요약의 "지금 장면:" 줄에서 시간대를 뺀 장소를 쓴다. "각자 있는 곳에서 통화" 같은 말은 장소로 보지 않는다.
- **이동하자고 할 때**: 이용자가 다른 곳으로 가자고 하면(분석기의 `scene_change_request`) 엔진이 `scene_change.explicit`로 기록하고, 장소가 실제로 바뀌는 때(그 턴이나 1~2턴 뒤) 마지막 결정 이후의 명시적 이동이면 **간격과 상관없이 즉시** 바꾼다.
- **그 밖에는 자주 바꾸지 않는다**: 장면이 새 장소에 3턴 이상 머물렀고, 마지막 변경에서 20분이 지났을 때만 바꾼다.
- 이용자가 직접 고른 배경은 건드리지 않는다. 맞는 배경이 없으면 그대로 두고(새로 만들지 않는다, `LOUNGE_AUTO_SCENE=make`일 때만 만든다), 무엇을 위해 결정했는지만 기억한다.

## 끄는 방법 (이용자)
1:1 대화방의 설정(대화 설정) › **배경 자동 전환**에서 켜기/끄기를 고른다. 대화방마다 따로이고 기본은 켜짐이다.
- **끄기**: 배경을 지금 그대로 두고, 이후 자동으로는 바뀌지 않는다(방의 background에 `auto_off`로 저장). 그래도 배경 설정에서 "장면에 맞게"를 누르면 한 번은 맞춰 주고 꺼진 상태는 유지된다.
- **켜기**: 직접 고른 배경이어도 자동 배경으로 돌려놓고, 결정해 둔 장면을 잊어서 지금 장소를 다시 본다.
- 배경을 직접 고르면 자동 전환은 꺼진다(설정에도 꺼짐으로 보인다).

## 어떻게 동작하나
- 페이지가 방을 열 때와 답이 올 때마다(답의 장면은 답보다 조금 늦게 저장되므로 2.5초, 9초 뒤 두 번) 서버에 묻는다. 대부분 아무것도 바뀌지 않는다(DB 읽기만).
- 서버(`api/lounge-images.ts`, action `scene`, `auto: true`)는 엔진 장면을 읽고 위 규칙으로 정한 뒤, 기본 장소와 공유 배경 중에서 AI가 가장 맞는 것을 고른다. 결정한 장면은 방의 background에 `follow`로 남긴다.

## 기본 장소(배경 전용, 2026-11-09 추가)
자동차 안(밤), 집 거실, 집 침실, 아늑한 식당, 비 갠 밤거리. 이미지는 `scripts/generate-lounge-scenery.mjs`로 만든다(gpt-image-2 low). 방, 공간, 시나리오는 이 다섯 장소로 만들지 않는다(DB의 장소 목록에 없음). 이용자가 배경 선택에서 직접 고르려면 `20261215000000_lounge_place_backgrounds.sql`을 실행해야 한다(이 SQL은 `arnobridge`가 빠져 있던 목록도 고친다).

## 아직 없는 것
갤러리, 수영장, 사무실 같은 장소의 기본 배경(맞는 게 없으면 배경이 그대로 유지된다).
