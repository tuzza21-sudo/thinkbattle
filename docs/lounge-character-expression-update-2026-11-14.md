**캐릭터 자기표현 개편 — 2026-11-14**

11월 14일 착수했고, 아래 검증은 11월 15일에 완료했다.

이후 새 대화에서 드러난 질문 반복·자기 비하 문제는 [서도현 후속 분석과 수정](./lounge-dohyun-confidence-audit-2026-11-15.md)에 기록했다. 아래 예시 8개 개편과 검증 결과는 그 후속 수정 이전의 기록이다.

사용자 요청에 따라 1:1 채팅·통화에서 캐릭터가 자기 경험과 현재 기분으로 반응하고 이야기를 함께 만들도록 공통 지침을 개편했다. 기존 다른 에디터의 변경을 바탕으로 필요한 부분만 수정했으며, 사주 계산과 화면·인증·결제·모델 제공자 설정은 변경하지 않았다.

- 공통 문장 수, 한 턴에 할 말 하나, 행동 개수, 질문 끝맺음 간격, 속마음 휴식 턴을 제거했다. 행동은 감정과 의도에 필요할 때 표현하며 빛·소품을 의무적으로 넣지 않는다.
- 1:1 캐릭터 정체성 지침을 그룹 토론용 지침과 분리했다. 가상 인물의 설정 안에서 자기 일상과 작은 과거 일화를 구체화하고, 질문받지 않아도 먼저 이야기할 수 있다. 실제 외부 사실과 사용자에게 속한 선택·동의·공유 과거는 구별한다.
- 관계 단계는 일상의 자기표현을 잠그지 않는다. 실제 비밀과 깊은 사연의 공개 시점, 확정된 관계·계약·말투 합의와 현재의 거절은 유지한다.
- 사전 분석은 사용자 요청과 현재 상황을 읽는다. 연출가가 감정과 반응을 정하는 경로는 기본적으로 사용하지 않으며 `LOUNGE_DIRECTOR=on`일 때만 사용할 수 있다. 실제 정정은 고치되 모든 인물에게 같은 진지한 반응을 강제하지 않는다.
- 캐릭터가 다음에 하고 싶은 일과 꺼내고 싶은 이야기를 `next_intent`에 남길 수 있다. 현재 장면을 유지한다는 것은 캐릭터의 행동과 화제 확장을 멈추라는 뜻이 아니다.
- 서도현의 일상·요리·와인·테니스·여행 취향을 첫 단계부터 열었다. 속마음과 예시 8개를 관찰·판단 보류 중심에서 구체적인 경험·자기 기분·관심으로 다시 썼다. 다른 캐릭터의 고유 설정은 유지한다.
- 1:1 지식·경험 카드는 교훈과 질문으로 끝낼 의무 없이 자기 삶의 이야기로 활용한다. 그룹 토론의 지식 사용 방식과 실제 사실의 기준 날짜는 유지한다.
- 저장 전에 별표 지문은 괄호로 정리해 내용을 보존하고, 네 번째 이후 행동과 200자·세 줄 이후 속마음을 삭제하지 않는다. 사용자가 속마음을 숨기는 설정과 그대로 반복한 속마음의 중복 제거는 유지한다.
- DB의 기존 메시지 저장 한도 안에서는 대사를 먼저 보존하고 남은 공간에 속마음을 담는다. 긴 속마음 때문에 음수 slice로 대사가 잘리는 경우를 방지했다. 채팅 생성 여유는 2,200 출력 토큰으로 늘렸다.
- 최근 네 발화는 중간의 일화가 사라지지 않도록 읽기·응답 컨텍스트에 보존한다. 새로 구체화한 자기 일화도 `self_facts` 기록 대상으로 명시했다.
- 기존 방의 과거 답변은 나눈 내용의 기록으로 유지하면서, 그 답변의 짧은 분량과 무른 반응을 따라 할 필요가 없음을 명시했다. 검색된 카드의 오래된 말투·교훈도 현재 캐릭터 설정을 덮어쓰지 않는다.

추가된 포커 캐릭터가 이미 사용하는 라운지·행사장 장면 종류를 공통 장면 목록에 반영했다. 해당 캐릭터의 점수·말투 설정은 바꾸지 않고 기존 테스트의 명단과 기대값을 현재 설정에 맞췄다. 허용 계정 방식의 테스트는 `LOUNGE_ADULT_MODE=allowlist`를 명시하도록 수정했으며 운영 권한 분기는 바꾸지 않았다.

검사는 실제 API 핸들러의 요청 구성, 행동·속마음 저장, 공개 범위, 장기 기억·합의·거절 처리와 제공자 fallback 등을 모킹한 회귀 테스트 및 TypeScript 빌드로 수행한다. 실제 유료 모델을 호출한 문체 비교와 운영 배포는 별도이며, 이번 코드 변경만으로 Kindroid와 동일한 출력 품질을 검증했다고 주장하지 않는다.
