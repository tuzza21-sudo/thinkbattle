# 전체 사진 헤드라인과 풍경·대화석 연결 · 2026-10-02

추가 축소: 메인의 열린 수다방 카드 사진을 PC 156→104px, 모바일 160→107px로 줄이고 제목·사진·참여 버튼 사이 여백을 함께 줄였다. 현재 카드 전체 높이는 약 224~238px다. 헤드라인은 직전 크기에서 다시 약 2/3로 줄여 PC 347→232px, 모바일 327→218px로 조정했다. 제목과 보조 문구를 유지하며 320·390·768·1024·1440px에서 텍스트 잘림, 가로 넘침, 만석 표시와 참여 링크를 확인했다. 프로덕션 빌드도 통과했다. [작아진 PC 메인](./lounge-compact-lobby-desktop.png) · [모바일 메인](./lounge-compact-lobby-mobile.png)

후속 조정: 메인 전체는 밝은 크림색을 유지하고 사진의 어두운 대비를 줄였다. 헤드라인 높이는 PC 520→347px, 모바일 490→327px로 약 2/3로 줄였다. 기존 사진에 밝기·채도 조정과 따뜻한 크림색 그라데이션을 적용하고 제목·보조 문구는 짙은 올리브색으로 바꿨다. 문구 내용은 유지한다. 320·390·768·1024·1440px에서 실제 높이, 텍스트 잘림과 가로 넘침을 확인했고 프로덕션 빌드를 통과했다. 대화방의 어두운 테마와 기존 블러·프로필 배치는 유지한다. [부드러운 PC 헤드라인](./lounge-soft-hero-desktop.png) · [모바일 헤드라인](./lounge-soft-hero-mobile.png)

메인 오른쪽의 클럽 라운지 사진을 헤드라인 영역 전체 배경으로 펼쳤다. 기존 사진 속 초대 문구를 제거하고 메인 제목을 **“문득 사람과의 대화가 하고 싶은 순간이 찾아올 때...”**로 바꿨다. 기존 보조 문구 두 문장과 참여 인원·실시간 음성·세션 안내를 사진 위에 유지한다. 크림색 본문과 구분되는 넓은 사진 헤더를 사용하고, 어두운 그라데이션과 밝은 글자로 가독성을 확보한다.

대화방에서는 풍경 하단 240px(모바일 210px)에 점진적인 12px 블러를 추가했다. 프로필은 PC 104px, 모바일 84px 위로 올려 흐려진 사진 하단에 살짝 겹치게 배치한다. 풍경 설명은 프로필보다 위에 남겨 겹치지 않도록 했다. 주제·조사 자료·발언 순서 패널은 참가자 프로필 아래로 옮겨 풍경과 사람 사이의 큰 간격을 줄였다.

오른쪽 대화 기록, 발언 상태, 손들기와 마이크 제어는 유지한다. 기존 이미지 `public/lounge/lounge-club-hero-v1.webp`를 재사용하며 새 이미지 생성이나 추가 SQL 실행은 없다.

프로덕션 빌드와 변경 파일 ESLint, 320·390·768·1024·1440px 및 1~6명 브라우저 검사를 통과했다. 새 제목과 전체 사진 배치, 풍경 설명과 프로필 사이의 간격, 기록 열기·닫기·Esc·포커스·초안 유지·반복 글 대화를 확인했다. 순서 발언·손들기·패스와 마이크 보호의 기존 브라우저 검사도 통과했다. 실제 여러 사용자 음성 대화는 이번 디자인 검사에 포함하지 않았다.
