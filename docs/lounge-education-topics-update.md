# 주제 선택 간소화와 자녀·교육

2026-10-04. 새 대화방은 다음 여섯 분야에서 주제를 직접 입력한다.

1. 미디어 / 문화 — 영화·책만 선택한다. 토글 옆에 작품명과 감독·저자를 입력한다.
2. 취미 / 취향 — 여행, 취미, 맛집 등. 좋아하는 것, 즐기는 활동, 기억에 남는 경험을 나눈다.
3. 연애 / 사랑
4. 커리어 / 진로
5. 재테크 / 경제
6. 자녀 / 교육

2~6번은 세부 분류를 선택하지 않는다. 내부 `subcategory`는 `general`로 저장하고 방장이 직접 적은 제목·계기·대화 방향으로 조사 범위를 정한다. 미디어의 영화·책 토글과 작품 정보는 데스크톱에서 한 줄이며 작은 모바일 화면은 토글 아래에 작품명·창작자 두 입력을 나란히 배치한다.

주제 설명을 작성하는 영역과 사회자 선택 사이 간격을 넓혔다. 사회자 제목은 “어떤 분위기의 사회자와 이야기할까요?”, 장소 제목은 “어떤 장소에서 대화할까요?”다. 고객 화면과 메타 정보의 “수다”, “수다방”은 “대화”, “대화방”으로 변경했다.

## 자녀·교육 사전 준비

`src/lib/loungeStudy.ts`의 검색 프롬프트와 `api/lounge.ts`의 사회자 지시에 교육 맥락을 추가했다. 방장이 공개한 아이의 연령대·교육 단계, 상황, 시도해 본 방법과 궁금한 점에 맞춰 조사한다. 연령이 없으면 추정하지 않고 질문으로 확인한다.

교육부·교육청·공공 교육 연구기관의 공식 안내와 공개 연구를 우선하며 연구 대상·맥락·한계를 확인한다. 정책·지원·입시 정보는 지역·대상·자료 기준 날짜를 확인한다. 학원 광고나 출처 없는 성공담을 검증된 효과로 쓰지 않는다.

질문은 실제 고민이 생긴 상황, 아이와 부모가 원하는 것, 시도한 방법과 변화, 선택의 장단점, 가정에서 존중하고 싶은 기준을 나눌 수 있도록 준비한다. 아이·학교·교사·가족의 신원을 검색하거나 능력·성격·진단·양육의 정답을 단정하지 않는다. 연구 사실·전문가 해석·개인 경험을 구분한다. 검색 결과를 방의 자료로 정리하는 방식이며 모델을 새로 훈련하지 않는다.

## 적용

SQL Editor에서 `20261004020000_voice_lounge_human_conversation.sql` 다음에 `20261004030000_voice_lounge_education_topics.sql` 전체를 실행하고 클라이언트·API를 배포한다. 이번 작업에서는 원격 DB에 실행하지 않았다.

기존 사회·이슈·방송 방과 예전 세부 분류의 방 소개·조사 자료는 원래 의미로 읽을 수 있도록 유지한다. 사회·이슈 자료를 자녀·교육으로 재해석하지 않는다. 새 방 생성 화면에는 이전 선택지를 제공하지 않는다.
