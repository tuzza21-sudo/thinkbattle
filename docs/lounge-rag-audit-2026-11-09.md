# 2026-11-09 선우령 대화의 RAG 반영 점검

조사 범위는 한국 시간 11월 9일 13:00~16:00, 앞선 중단 조사에서 확인한 두 대화방이다. 운영 DB와 답변 본문, 검색 코드, 지식 카드 내용을 대조했다. 운영 데이터와 서비스 코드는 변경하지 않았다.

## 판단

이 구간에서는 기본 캐릭터 설정과 대화 맥락의 영향이 주로 보이며, 등록된 전문 지식이나 일화가 뚜렷하게 활용된 답변은 확인하지 못했다. 이것은 내용 대조 결과이며, RAG 검색 성공률이나 프롬프트 주입률이 0%라는 뜻은 아니다.

지식 카드 32개는 모두 10월 26일에 생성·수정됐으며, 조사 대상 대화 이후 수정된 카드는 없었다. 현재 운영 환경변수 목록에는 지식 검색 비활성화나 유사도 임계값 변경을 위한 변수가 없다. 현재 코드는 기본적으로 지식 검색을 사용한다. 다만 현재 설정 목록만으로 당시 모든 요청의 실행 상태를 증명할 수는 없다.

## 정확한 반영률을 계산할 수 없는 이유

- `lounge_character_knowledge_uses`는 일반 지식의 사용을 기록하지 않고 일화 선택만 기록한다. 일화 기록 0건을 전체 RAG 호출 0건으로 해석하면 안 된다. 선택 시점의 기록이므로 답변에서 실제 말했는지를 확정하는 기록도 아니다.
- 기본적으로 최근 사용자 발언 두 개(최대 400자)를 검색어로 삼고, 지식은 유사도 0.33 이상에서 최대 두 개, 일화는 0.45 이상에서 최대 한 개를 고른다. 조회가 늦거나 실패하면 지식 없이 답변한다. 음성 통화는 전문 지식 검색을 건너뛴다. 현재 방의 음성 설정은 당시 매 턴의 설정 이력이 아니다.
- 당시 함수 로그는 앞선 조사에서 보관 기간 초과로 조회할 수 없었다. 저장된 39개 턴의 후처리 payload도 모두 비어 있으며, 코드상 적용 완료 후 비우는 구조다. 검색된 카드 ID, 답변 프롬프트에 포함됐는지, 모델이 실제로 활용했는지를 턴별로 복원할 자료가 없다.

향후 정확히 측정하려면 검색 후보·실제 프롬프트 포함 카드·검색 실패/시간 초과·답변의 사용 여부를 구분해야 한다. 우선 카드 ID와 처리 시간, 완료 여부만 남겨도 ‘검색 실패’와 ‘검색됐지만 답변에서 쓰지 않음’을 가를 수 있다.

## 실행 범위

새 임베딩으로 당시 검색을 재현하는 실험은 실행하지 않았다. 사적 대화를 외부 임베딩 API로 재전송하는 실행이 자동 승인 검토에서 거절되어, 남아 있는 내부 기록과 내용 대조로 조사했다. 전체 환경변수를 복호화하는 조회도 승인 검토에서 거절됐으며, 대신 비밀값을 읽지 않는 환경변수 목록 조회만 수행했다. 대화 원문은 공개 문서에 옮기지 않았다.
